# 図書館データセット

都道府県別の公共図書館に関する統計データです。DEA（データ包絡分析）のサンプルデータとして利用できます。

## ファイル

- `library_prefecture.csv` - 47都道府県の図書館統計データ（令和2年度）

## 項目

| 列名 | 説明 |
|------|------|
| 都道府県 | 都道府県名 |
| 図書館数 | 図書館の数 |
| 専任職員数 | 専任職員の数 |
| 非常勤職員数 | 非常勤職員の数 |
| 司書数 | 司書の数（専任＋非常勤） |
| 図書冊数 | 所蔵図書の冊数 |
| 登録者数 | 図書館利用登録者の数 |
| 貸出冊数 | 図書の貸出冊数 |
| 視聴覚資料貸出数 | 視聴覚資料の貸出数 |
| レファレンスサービス実施件数 | レファレンスサービスの実施件数 |
| 読書会実施件数 | 読書会・研究会の実施件数 |
| 鑑賞会実施件数 | 鑑賞会・映写会の実施件数 |
| SNS利用館数 | ソーシャルメディアを利用している図書館の数 |

## 出典

本データは以下の統計データを都道府県別に加工・集約したものです。

- 出典：文部科学省「社会教育調査」（令和3年度）
- データ取得元：e-Stat（政府統計の総合窓口） https://www.e-stat.go.jp/
- ライセンス：公共データ利用規約（第1.0版） https://www.digital.go.jp/resources/open_data/public_data_license_v1.0
